# Profile Page

## 📌 About the Project

This is a personal profile page I created as a practice project while learning front-end web development. The project focuses on building a simple, organized, and visually appealing webpage using HTML and CSS.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Features

* Personal profile information
* Profile image
* About Me section
* Interests and hobbies
* Styled links
* Responsive page layout

## 📚 What I Learned

Through this project, I practiced:

* Structuring webpages with HTML
* Using semantic HTML elements
* Styling elements with CSS
* Working with fonts, colors, spacing, and layouts
* Using images within a webpage
* Organizing a front-end project

## 🎯 Purpose

This project was created to strengthen my foundational HTML and CSS skills and gain hands-on experience building a webpage from scratch.
